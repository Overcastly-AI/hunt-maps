`R9` is **updated in place, research half done**. The register now scores the
shipped model against 40 published regional peaks; the implementation half
still needs a build agent. Two corrections to what this row previously said,
both from sources rather than reasoning:

- The row asserted southern timing is driven by restocking **genetics**. That
  is stronger than the evidence — Sumners et al. 2015 found no nuclear-DNA
  separation (P = 0.200); only mtDNA separates herds, a maternal effect. The
  practical consequence is worse, not better: the effect is **not recoverable
  from any covariate the engine has**, so no feature substitutes for a region
  table.
- The row's "drop `rutConfidence` below 36°N to ~0.15" is **replaced by
  refusal**. 0.15 is still a date on a chip, and the measured error reaches
  131 days. Return UNKNOWN instead. Separately, `rutConfidence` currently
  returns a number that is not the probability of anything; `docs/EVIDENCE.md`
  now prescribes a falsifiable definition and a six-tier ladder to key it on.
